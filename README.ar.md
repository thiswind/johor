# وكيل JOHOR

[English](README.md) · [中文](README.zh-CN.md) · [العربية](README.ar.md)

<div dir="rtl">

وكيل ذكي شخصي لمستخدم واحد، مبني عمداً لـ **تيليجرام**.

JOHOR يخاطب مستخدماً واحداً محدَّداً — محادثة بشخصية ثابتة، وفهم للصور، وتوليد صور، وبحث حي في الويب، وصوت بالاتجاهين (استماع وتحدّث)، وموسيقى عند الطلب، ومهام مجدولة، ونظام مهارات يتوسع بالتعلّم. مستودع واحد تنسخه وتضبطه ويشتغل.

هذا منتج مستقل، ليس إعداداً لمشروعه الأصل. انطلق من لقطة من [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent) 0.13.0 (أغسطس 2026) ثم افترق عمداً: نحو 60% من الشجرة الأصلية أُزيلت. JOHOR لا يتعقب الأصل ويطور مساره بنفسه.

## لماذا «الضيق» يتفوق على «العموم»

hermes-agent إطار وكلاء عام: عشرات منصات المراسلة، وكل شيء قابل للضبط، وميزات تُسوّى عبر كل الأهداف. لهذه العمومية ثمن — حين يجب على المهايئ أن يرضي اثنتي عشرة منصة، لا يبدع في أي واحدة.

JOHOR راهن على العكس:

- **تيليجرام فقط.** مهايئ واحد للمنصة، مضبوط بعمق: معالجة الوسائط، والرسائل الصوتية، والرسائل الطويلة، والتعديل بعد الإرسال.
- **مستخدم واحد محدَّد.** لا شيء متعدد المستأجرين إطلاقاً. الجلسة والذاكرة وحالة الشخصية تفترض إنساناً واحداً.
- **منصة قدرات قصيرة ورافضة للمساومة** (أدناه)، كل حلقة فيها تُختبر يومياً في الإنتاج.

وتيليجرام نفسه يستحق هذا الإخلاص: Bot API مجاني، وحدود كريمة للرسائل والملفات، ورسائل صوتية أصلية، ودعم وسائط من الطراز الأول، وضريبة منصة معدومة، وعميل حقيقي على كل نظام تشغيل. للوكيل الشخصي، هو ببساطة أفضل قاعدة.

ما قُطع في التشذيب: 19 مهايئ منصات غير مستخدمة، وموقع التوثيق، وكتالوج المهارات الاختيارية، وواجهة TUI المدمجة — كلها رحلت. وبقي ما يركضه فعلاً وكيل تيليجرام الشخصي.

## القدرات

| القدرة | ما يراه المستخدم |
|---|---|
| المحادثة | حوار طويل بشخصية ثابتة؛ ضغط تلقائي للسياق بلا فقدان ذاكرة في منتصف الحديث |
| الرؤية | أرسل صورة أو لقطة شاشة واسأل عنها |
| توليد الصور | صِف الصورة، واستلمها |
| البحث الحي | استرجاع لحظي بإجابات موثقة المصادر |
| الصوت (استماع) | أرسل رسالة صوتية فتُنسخ وتُفهم |
| الصوت (تحدّث) | يمكن تركيب الردود صوتياً |
| الموسيقى | صِف الأسلوب/المزاج/اللغة، فتصلك مقطوعة كاملة خلال دقيقة أو دقيقتين |
| المهام المجدولة | تذكيرات ومهام دورية بلغة طبيعية |
| المهارات | مستندات مهارات قابلة للتحميل؛ الوكيل يتعلم مهارات جديدة |

## متطلبات النموذج (اقرأ أولاً)

JOHOR وكيل كثيف الأدوات: الدورة الواحدة قد تُسلسل نداءات أدوات متعددة مع التزام بالتعليمات عبر سياق طويل. **النموذج الرئيسي هو أكبر عامل منفرد في جودة كل هذا.** النموذج الضعيف يُنتج استخدام أدوات متدهوراً بوضوح — وسائط منسية، وخطط منسية، وحلقات مكسورة.

الحد الأدنى للنموذج الرئيسي (أيٌّ من):

| المزوّد | الحد الأدنى |
|---|---|
| Anthropic | Claude Opus 5 (`claude-opus-5`) أو أحدث |
| OpenAI | GPT-6 Astra (`gpt-6-astra`) أو أحدث |
| DeepSeek | سلسلة DeepSeek-V4.1 أو أحدث |
| Zhipu (Z.ai) | GLM-5.3 أو أحدث |

قاعدة عملية: النموذج الذي لا يستطيع تشغيل منظومة نداء أدوات وكيلية بنظافة هو دون المستوى؛ وكل ما يبلغ هذه المستويات يعمل جيداً.

## منظومة الدعم

هذه **نسخة منتقاة (curated build)**: الخدمات أدناه هي ما اختير ووُصل وحُسِّن ويُختبر يومياً. **ما ليس مذكوراً غير مدعوم** — لا ذيل طويل من تكاملات نصف عاملة بانتظارك، ولا شيء في قائمة «دعم قادم». القدرات التي تهم هذا الوكيل كلها في الجدول؛ وما ليس فيه، لا يفعله.

| الدور | الخدمة / النموذج |
|---|---|
| النموذج الرئيسي | GLM-5.3 (نقطة نهاية بروتوكول Anthropic) |
| الرؤية + المهام المساعدة | GLM-5.3-Flash |
| توليد الصور | gpt-image-2 |
| البحث الحي | **Perplexity (sonar) — محرك البحث الأول بلا منازع** |
| استخراج صفحات الويب | Tavily |
| تحويل الكلام إلى نص | scribe_v3 |
| تحويل النص إلى كلام | eleven_v4 (صوت Rachel) |
| توليد الموسيقى | Suno |
| محرك السياق | cursor_style (مدمج؛ انظر أدناه) |

النموذج الرئيسي قابل للتبديل (أي مزوّد يبلغ الحد أعلاه يعمل عبر ضبط النقطة نفسه)، لكن خدمات الوسائط المتعددة هي ما حُسِّنت له هذه النسخة.

وعن البحث، موقف مقصود: **Perplexity هو محرك البحث الأول الوحيد.** هذا الوكيل يُستخدم في عمل جاد، والعمل الجاد يحتاج جودة استرجاع — محركات عصر الكلمات المفتاحية تعيد قمامة متنكرة في هيئة إجابات. المحركات الأخرى تبقى قابلة للضبط تقنياً، لكنها من الدرجة الثانية وتُعامل كذلك.

امتلاكك لمفاتيح أيٍّ من هذه الخدمات شأنك الخاص. الكود لا يسأمن أين جاء المفتاح.

### شراء المفاتيح دون جمع المزوّدين

الشراء مباشرة من كل مزوّد أعلاه يعني عدة حسابات وفواتير. منصتان تجميعيتان تغطيان معظم المنظومة بحساب ومفتاح واحد:

- [OpenRouter](https://openrouter.ai) — كتالوج نماذج واسع وفاتورة واحدة
- [apinexus.pro](https://apinexus.pro) — وصول شامل لخدمات الوسائط أعلاه

بأيهما، املأ الـ base URL والمفتاح في `config.yaml` وكنت شغّلت منظومة الدعم.

## البدء السريع

```bash
git clone https://github.com/thiswind/johor
cd johor
uv sync                                   # بناء البيئة من ملف القفل
cp config.example.yaml ~/.hermes/config.yaml
$EDITOR ~/.hermes/.env                    # املأ مفاتيح الـ API الخاصة بك
python -m hermes_cli.main gateway run     # تشغيل بوابة تيليجرام
```

تحتاج توكن بوت تيليجرام من [@BotFather](https://t.me/BotFather)؛ كل ما عدا ذلك مفاتيح في `.env`. يوثّق `config.example.yaml` كل قسم بقيم عامة سليمة — نقاط النهاية وأسماء النماذج والمفاتيح — مع أماكن الأسرار فارغة لتملأها.

الشجرة العامة هي نفس الكود الذي يعمل في الإنتاج، ناقص بيانات الاعتماد وتفاصيل النشر الخاصة. إن لم تعمل بعد النسخ، فذلك علة (bug).

## محرك السياق: cursor_style

المحادثات الطويلة يضغطها محرك بأسلوب Cursor ‏(`plugins/context_engine/cursor_style/`، افتراضي المستودع):

- يحمي توجيه النظام فقط — كل دور قابل للضغط، فيستطيع الموضوع الانجراف فعلاً بدل سحبه عائداً إلى الدور الأول
- عدّ رموز tiktoken دقيق بوعي CJK ‏(أدق 2.5–2.9 مرة من `chars//4` الساذج للصينية والعربية)
- النص الكامل قبل الضغط يُؤرشف JSONL — الملخصات تربط بالمرجع والتفاصيل قابلة للاسترجاع
- تقليم مخرجات الأدوات، وملخصات تزايدية، وتبريد ضد التذبذب، كلها حاضرة

يُطوَّر المحرك علناً في [hermes-cursor-compressor](https://github.com/thiswind/hermes-cursor-compressor)؛ ويضمّن هذا المستودع نسخة كافتراضي.

## نموذج الأمان

يعمل النشر المرجعي الوكيل تحت صندوق حماية systemd مشدد: ‏`ProtectSystem=strict` بمسار منزلي واحد قابل للكتابة، و`NoNewPrivileges`، ومجموعة قدرات فارغة، وseccomp ‏`@system-service`. قالب وحدة الصندوق مرفق في `customizations/johor-agent.service`. التثبيت مثبَّت بالإصدارات (`uv.lock` دقيق)، وقنوات التحديث الذاتي معطّلة بالتصميم.

## الاختبارات

```bash
scripts/run_tests.sh          # الكامل (يُنصح به على Linux/WSL)
```
